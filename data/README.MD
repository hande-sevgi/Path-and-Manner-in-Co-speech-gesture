# Data

This directory documents the datasets for the five studies reported in Chapter 3 of Hande Sevgi's dissertation.

## Directories

- `input/` documents the source data archived on OSF.
- `processed/` contains analysis-ready datasets.
- `codebook/` explains variables, experimental codes, and permissible values.

## OSF archive

The authoritative research archive is available at:

https://osf.io/buftx/

Raw files should never be edited manually. All data transformations and participant exclusions must be implemented in reproducible R code.
