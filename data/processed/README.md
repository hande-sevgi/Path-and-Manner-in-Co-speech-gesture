# Processed data

This directory contains analysis-ready datasets generated from files in `data/input/`.

The processing workflow will:

1. Validate required columns.
2. Decode compact trial labels.
3. Create explicit experimental variables.
4. Replace platform response identifiers with anonymous study identifiers.
5. Apply documented participant-exclusion rules.
6. Record inclusion status and exclusion reasons.
7. Write consistent analysis-ready CSV files.

Files in this directory should be generated by R and should not be edited manually.
