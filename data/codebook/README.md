# Data Codebook

This codebook explains the structure and meaning of the five datasets associated with Chapter 3 of Hande Sevgi’s dissertation.

Each row in a dataset represents one participant’s judgment for one experimental trial. Participants evaluated how natural or appropriate an English sentence or multimodal utterance was in a particular context.

Ratings were recorded using a continuous scale from 0 to 100.

* `0` represents an extremely unlikely or unnatural judgment.
* `100` represents an extremely likely or natural judgment.
* Values between 0 and 100 represent gradient judgments.

## Common source variables

### `Response_ID`

`Response_ID` is a participant identifier generated by the survey platform.

Example:

```text
R_8Qzw3Tbgzh0aVIl
```

It distinguishes one participant’s responses from another participant’s responses. It is not the participant’s name.

### `Trial`

`Trial` is a compact code containing information about the experimental condition.

Its interpretation differs slightly across studies. Therefore, a trial code must always be interpreted in relation to its dataset.

### `Rating`

`Rating` is the participant’s judgment on the 0–100 response scale.

Example:

```text
Rating = 85
```

This means the participant considered the sentence or utterance relatively likely or natural in the presented context.

### `Order`

`Order` identifies the order of the path and manner modifiers in the written experiments.

| Code  | Meaning                                     |
| ----- | ------------------------------------------- |
| `P_M` | Path modifier occurs before manner modifier |
| `M_P` | Manner modifier occurs before path modifier |

## Shared experimental codes

### Polarity

| Code  | Meaning              |
| ----- | -------------------- |
| `Aff` | Affirmative sentence |
| `Neg` | Negative sentence    |

### Path, manner, and conflated information

| Code | General meaning                       |
| ---- | ------------------------------------- |
| `P`  | Path information                      |
| `M`  | Manner information                    |
| `C`  | Conflated path-and-manner information |
| `0`  | Absence of the relevant information   |

The interpretation of `0` depends on its position and study:

* In an event position, `0` means **no motion**.
* In a gesture position, `0` means **no gesture**.

### Scenario

| Code | Entity depicted |
| ---- | --------------- |
| `A`  | Leaf            |
| `B`  | Car             |
| `C`  | Paper           |
| `D`  | Plank           |
| `E`  | Chair           |

A scenario label may include a numeric suffix, such as `A_1`. The letter identifies the entity. The precise function of the numeric suffix must be confirmed from the experimental materials.

# Study-specific trial structures

## Experiment 1: Written English — path before manner

Dataset:

```text
exp1_written_path_manner.csv
```

Trial structure:

```text
Polarity ModificationType EventType Scenario
```

Example:

```text
Neg P 0 A_1
```

Interpretation:

| Component         | Code  | Meaning                                 |
| ----------------- | ----- | --------------------------------------- |
| Polarity          | `Neg` | The sentence is negative                |
| Modification type | `P`   | The sentence contains path modification |
| Event type        | `0`   | The animated context depicts no motion  |
| Scenario          | `A_1` | The depicted entity is the leaf         |

In plain language:

> A participant evaluated a negative sentence containing path information while viewing a no-motion event involving the leaf.

Another example:

```text
Aff M C E_1
```

Interpretation:

> A participant evaluated an affirmative sentence containing manner modification while viewing a conflated path-and-manner event involving the chair.

The modifier order for this experiment is:

```text
P_M = path before manner
```

## Experiment 2: Written English — manner before path

Dataset:

```text
exp2_written_manner_path.csv
```

Trial structure:

```text
Polarity ModificationType EventType Scenario
```

Example:

```text
Aff C P B_1
```

Interpretation:

| Component         | Code  | Meaning                                                 |
| ----------------- | ----- | ------------------------------------------------------- |
| Polarity          | `Aff` | The sentence is affirmative                             |
| Modification type | `C`   | The sentence contains both path and manner modification |
| Event type        | `P`   | The animated context depicts a path event               |
| Scenario          | `B_1` | The depicted entity is the car                          |

In plain language:

> A participant evaluated an affirmative sentence containing both path and manner modification while viewing a path event involving the car.

The modifier order for this experiment is:

```text
M_P = manner before path
```

## Baseline Study 1: No gesture

Dataset:

```text
baseline1_no_gesture.csv
```

Trial structure:

```text
Polarity EventType Scenario
```

This dataset does not contain a gesture-type component because the spoken utterances were presented without gesture.

Example:

```text
Neg C C_1
```

Interpretation:

| Component  | Code  | Meaning                                                        |
| ---------- | ----- | -------------------------------------------------------------- |
| Polarity   | `Neg` | The spoken sentence is negative                                |
| Event type | `C`   | The animated context depicts a conflated path-and-manner event |
| Scenario   | `C_1` | The depicted entity is the paper                               |

In plain language:

> A participant evaluated a negative spoken sentence without gesture while viewing a conflated event involving the paper.

## Baseline Study 2: No event context

Dataset:

```text
baseline2_no_event.csv
```

Trial structure:

```text
Polarity GestureType Scenario
```

This dataset does not contain an event-type component because participants evaluated the utterances and gestures without an animated event context.

Example:

```text
Neg C C_1
```

Interpretation:

| Component    | Code  | Meaning                                                  |
| ------------ | ----- | -------------------------------------------------------- |
| Polarity     | `Neg` | The spoken sentence is negative                          |
| Gesture type | `C`   | The speaker produces a conflated path-and-manner gesture |
| Scenario     | `C_1` | The utterance concerns the paper scenario                |

In plain language:

> A participant evaluated a negative spoken utterance accompanied by a conflated path-and-manner gesture involving the paper scenario, without an animated event context.

This example demonstrates why the dataset must always be identified before interpreting `Trial`: the same compact code has a different structure in Baseline Studies 1 and 2.

# Derived variables

The reproducible R workflow will separate each compact `Trial` code into explicit variables.

For example:

```text
Aff M P E_1
```

will become:

| Variable        | Value         |
| --------------- | ------------- |
| `polarity`      | `affirmative` |
| `gesture_type`  | `manner`      |
| `event_type`    | `path`        |
| `scenario_code` | `E`           |
| `scenario`      | `chair`       |
| `item_version`  | `1`           |

This expanded structure is easier to validate, analyze, and understand than the original compact code.

## Inclusion variables

The processed datasets will also contain:

### `included`

Indicates whether a participant is retained in the statistical analysis.

Permitted values:

```text
TRUE
FALSE
```

### `exclusion_reason`

Documents why a participant was excluded.

Examples may include:

```text
low_response_variability
reported_inattention
```

The exclusion process must be implemented in R and documented rather than performed through undocumented manual editing.
