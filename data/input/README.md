## Processing status of the input files

The input datasets are organized research files rather than original Qualtrics exports. Most contain the complete recruited sample, allowing exclusions to be reproduced in R.

The Baseline 1 dataset is an exception. One participant who consistently selected the slider midpoint was removed before the dataset was shared.

| Study | Recruited | Present in input file | Processing status |
|---|---:|---:|---|
| Experiment 1 | 150 | 150 | Exclusions will be reproduced in R |
| Experiment 2 | 120 | 120 | Exclusions will be reproduced in R |
| Baseline 1 | 41 | 40 | One exclusion was applied before sharing |
| Baseline 2 | 40 | 40 | No participants were excluded |
| Experiment 3 | 150 | 150 | Exclusions will be reproduced in R |

Because the excluded Baseline 1 response is not included in the shared input file, its exclusion cannot be independently recomputed from this repository. The reason and resulting sample size are documented for transparency.
